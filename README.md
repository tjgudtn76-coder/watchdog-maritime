# Watchdog Maritime

**국제 해운시장 · 선박투자 · 선박운용의 최신 소식을 AI가 인터넷에서 찾아 이슈별 카드뉴스로 정리하고, 그 자료를 근거로 산업 전반의 향후 전망까지 분석해 주는 도구**입니다.

선박운용회사·선박투자회사 담당자가 흩어진 뉴스·정부 발표·시장 보고서를 일일이 찾아 읽고 정리하던 일을 줄이기 위해 만들었습니다.

## 무엇을 하나요

| 항목 | 하는 일 |
|---|---|
| **What's new** (뉴스 취합 및 정리) | 해운시장 · 선박투자·금융 · 선박운용 3개 분야를 동시에 웹 검색해, 최근 한 달 안의 이슈를 분야별 3건 이내로 정리합니다. 이슈 1건이 카드뉴스 1페이지입니다. |
| **What's next** (산업 전반 향후 전망) | What's new에서 모은 자료를 근거로 분야별 전망(긍정·중립·부정), 위험 요인, 지켜볼 점을 씁니다. 근거 자료 번호를 함께 보여 줍니다. |
| **관심 키워드** | 두 항목 각각에 키워드를 넣으면 그 키워드를 중심으로 더 자세히 정리합니다. 전망 쪽 키워드는 인터넷을 한 번 더 검색해 추가 자료로 씁니다. |
| **통합 보고서** | 뉴스 카드와 전망 카드를 한 보고서로 묶어 글로 복사할 수 있습니다. |

화면은 바다 느낌으로 디자인했습니다. (카드는 물결 머리, 배너에는 흐르는 물결과 컨테이너선)

## AI가 지키는 규칙

- 최근 31일 이내 자료만 인용합니다. 더 오래됐거나 날짜를 알 수 없는 자료는 코드가 한 번 더 걸러냅니다.
- 모든 이슈에 출처 이름·링크·날짜를 붙입니다. 출처 주소가 실제 웹 검색 결과에 없으면 그 이슈를 뺍니다. (없는 기사를 지어내지 않기)
- 전망은 근거 자료 번호가 있어야 하고, 없으면 "중립 + 근거 확인 필요"로 바꿉니다.
- 결과는 **참고용 초안**이며 최종 판단은 담당자가 합니다.

## 기술

- Next.js (App Router) · React · TypeScript · Tailwind CSS
- OpenAI API (모델 `gpt-4o-mini` 고정, 웹 검색 도구 사용) — 서버 쪽에서만 호출
- Vercel 배포, 접속 보호(비밀번호 확인, `proxy.ts`)
- 서버에는 아무것도 저장하지 않고, 작업 내용은 이 컴퓨터의 브라우저에만 임시 저장합니다.

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 실행하려면 프로젝트 폴더에 `.env` 파일을 만들고 아래 값을 넣어야 합니다. (이 파일은 저장소에 올리지 않습니다)

| 이름 | 용도 |
|---|---|
| `OPENAI_API_KEY` | OpenAI API 키 (필수) |
| `APP_PASSWORD` | 접속 비밀번호 (배포 환경에서 필수. 내 컴퓨터에서 개발할 때는 없으면 열려 있음) |

## 폴더 구조

| 위치 | 하는 일 |
|---|---|
| `app/page.tsx`, `app/components/` | 화면 (3단계 작업 화면, 카드뉴스 페이지) |
| `app/api/news`, `app/api/outlook` | 뉴스 취합 API, 전망 API |
| `app/lib/` | AI 호출, 지시문, 정해진 모양, 출처·날짜 검사 |
| `proxy.ts` | 접속 보호 |

## 참고

- 배포 환경에서는 화면과 API 모두 비밀번호 확인으로 보호됩니다. (AI 사용 비용을 아무나 쓰지 못하게 하기 위함)
- 이 프로젝트는 AI가 만든 초안을 보여 주는 도구이며, 투자·계약 등의 최종 판단을 대신하지 않습니다.
