# 탐지율 시험 사례

AI가 법령 개정안에서 **바뀐 조문을 얼마나 빠짐없이 찾는지** 재는 시험입니다. (PRD 성공 기준: 영향 조항 탐지율 90% 이상)

## 들어 있는 사례

| 폴더 | 내용 | 정답 |
|---|---|---|
| `ship-amend-12/` | **시험용 가상 개정안.** 선박투자회사법의 실제 조문 12곳을 일부러 고친 신·구 조문 대비표 (실제 개정이 아닙니다). 바뀌지 않은 조문 2개(제4조, 제20조)가 섞여 있어요. | 바뀐 조문 12개. 바뀌지 않은 조문이 나오면 안 됨 |
| `no-change/` | 바뀐 곳이 하나도 없는 대비표 | 영향 항목 0건 |

각 폴더에는 `law.txt`(개정안 글자)와 `answer.json`(정답표)이 있습니다.

## 시험하는 방법

1. 개발 서버를 켭니다.
   ```bash
   npm run dev
   ```
2. 다른 터미널에서 시험을 실행합니다. (AI를 실제로 부르므로 호출 비용이 들고, 1~3분 걸립니다.)
   ```bash
   npm run test:detection
   ```
   빨리 한 번만 보려면 `node test-cases/run-detection.mjs --runs 1`

## 결과 읽는 법

- **찾음 12/12 (100%)**: 정답 12개 중 AI가 찾은 개수와 비율입니다. 사례를 3번 돌린 **평균이 90% 이상**이면 통과입니다.
- **오탐**: 정답이 아닌 조문을 근거로 낸 항목 수입니다.
- **코드검사로 제외**: 근거를 확인하지 못해 코드가 뺀 항목 수입니다.
- 맞힘 기준: AI 항목의 "근거 조문"에 정답 조 번호가 들어 있으면 찾은 것으로 셉니다.

## 새 사례를 추가하려면

`test-cases/<새 이름>/` 폴더를 만들고 `law.txt`와 `answer.json`(`정답조문`, `나오면안되는조문`)을 넣으면 시험 도구가 자동으로 함께 돌립니다.
